DRIPCORE AUTOMATIC TOKEN DROPS UPDATE
=====================================

WHAT THIS ADDS
- A random drop appears every 10 minutes.
- Each drop contains 1, 2, or 3 Power Tokens.
- The first member to click the claim button wins.
- The claim button expires after 15 seconds.
- Claimed tokens are added directly to the winner's balance and ledger.
- Duplicate claims are blocked with an atomic database transaction.
- Active drops are safely expired after a restart.

INSTALL
1. Upload the included src folder into the root of your bot repository.
2. Replace the matching files when prompted.
3. Run: npm run deploy
4. Restart/redeploy the bot.

CHANNEL SETUP
The bot first uses the configured Automatic Token Drops Channel.
Run:
/config set-channel key:Automatic Token Drops Channel channel:#general

If this is not configured, the bot automatically looks for a text channel named
#general, then another channel containing "general", then the server system channel.

NOTES
- The first drop is scheduled for about 10 minutes after the update starts.
- The database tables are created automatically.
- The bot needs View Channel, Send Messages, Embed Links, and Read Message History
  permissions in the selected channel.
