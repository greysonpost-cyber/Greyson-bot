DRIPCORE GIVEAWAY BOOST PRICES UPDATE

Changes included:
- Giveaway boost menu now allows only:
  • +1 bonus entry for 3 Power Tokens
  • +3 bonus entries for 10 Power Tokens
  • Spider-Man passive for a free +1 entry once every 24 hours
- Removed the +5 entry option.
- Giveaway embeds now clearly display each boost and its price.
- Token charges, entry increases, insufficient-balance messages, transaction history, and leave refunds use the new prices correctly.

INSTALLATION
1. Upload the included src folder to the root of your bot repository.
2. Replace the matching file when prompted:
   src/handlers/giveawayHandler.js
3. Restart/redeploy the bot.

No database migration or slash-command redeployment is required for this update.
