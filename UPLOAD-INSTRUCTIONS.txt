DRIPCORE PRISMATIC PUNISHER + INVENTORY PATCH

1. Upload the included src folder into the ROOT of your GitHub repository.
2. Replace the matching files.
3. Restart/redeploy Railway.
4. Run: npm run deploy

CREATE THE ONE-OF-ONE:
/artifact create-punisher role:@The Punisher price:100

The command creates exactly one numbered copy and replies with both its Type ID and Artifact ID.

SPIDER-VERSE ROLE RULE:
A user qualifies by owning either:
- Spider-Man + Web Slinger/Web Swing + Friendly Neighborhood, OR
- The Punisher alone.

The Punisher is NOT a fourth requirement.

After creating or transferring it, run this once if needed:
/collection reward sync collection:Spider-Verse

INVENTORY:
/artifact collection
Now shows the unique Artifact ID, rarity, collection, passive, and trade/listing status for every owned copy.
