DRIPCORE TOURNAMENT — REMOVE POWER TOKEN BOOSTS

1. Upload the included src folder into the root of your bot repository.
2. Replace the matching file when prompted:
   src/handlers/tournamentHandler.js
3. Restart/redeploy the bot.

No database migration or slash-command redeployment is required.

CHANGES
- Removed the tournament Power Token boost select menu.
- Players can no longer buy +1, +3, or +5 tournament starting points.
- Removed Power Token boost information from tournament embeds.
- Updated tournament join and leave messages.
- Tournament powers can still be added later for individual games.

Existing historical token bonus points remain in the database and continue to count on old tournaments; this update only prevents new purchases.
