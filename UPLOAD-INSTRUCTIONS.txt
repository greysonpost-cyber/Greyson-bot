DRIPCORE GIVEAWAY HOST + DRIP TAG + EDIT PATCH

1. Upload the included src folder into the root of your GitHub repository.
2. Replace the matching files when prompted.
3. Keep your existing Railway database volume/data.
4. Redeploy or restart the bot.
5. Run: npm run deploy

NEW GIVEAWAY START OPTIONS
/giveaway start
- prize: required
- duration: required (examples: 30m, 2h, 1d)
- channel: optional
- winners: optional
- host: optional; defaults to the person running the command
- require_drip_tag: optional Yes/No; defaults to No
- required_role: optional
- required_guild_role: optional

The clan tag is always DRIP. Managers are never asked to type a custom tag.

NEW EDIT COMMAND
/giveaway edit
- Paste the active giveaway message link.
- Change any included option; leave other options blank to keep them unchanged.
- Supported edits: prize, host, remaining duration, winner count, channel,
  DRIP tag requirement, required Discord role, required guild rank, and lock status.
- Use clear_required_role or clear_required_guild_role to remove requirements.
- Existing entrants and their entry counts are preserved.

WHO CAN EDIT
- The selected giveaway host
- Configured Giveaway Manager role
- Configured Giveaway Staff role
- Administrators / Manage Server

DATABASE
The require_clan_tag column is installed automatically on startup.
Existing giveaways remain DRIP-tag-required for compatibility. New giveaways use
the selected require_drip_tag option and default to No when omitted.
