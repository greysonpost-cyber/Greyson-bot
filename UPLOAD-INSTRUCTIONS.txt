DRIPCORE TOURNAMENT EDIT POINTS PATCH

1. Open your GitHub bot repository.
2. Upload the included src folder into the repository root.
3. Replace the two matching files when GitHub asks.
4. Redeploy/restart Railway.
5. Run: npm run deploy

NEW COMMAND
/tournament edit-points

Options:
- user: player to edit
- category: displayed total, contribution, or rounds 1-4
- action: set, add, or remove
- amount: number of points
- reason: optional audit note

Examples:
/tournament edit-points user:@Greyson category:Round 2 action:Set amount:10
/tournament edit-points user:@Greyson category:Displayed total action:Add amount:3
/tournament edit-points user:@Greyson category:Round 1 action:Remove amount:2

Only Tournament Managers and server administrators can use it. The live tournament panel updates automatically.
