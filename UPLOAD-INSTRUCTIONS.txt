DRIPCORE COLLECTION ROLE REWARDS PATCH
======================================

1. Upload the included src folder into the root of your current repository.
2. Replace the matching files when prompted.
3. Run: npm run deploy
4. Restart/redeploy the bot.

The database table is created automatically when the bot starts.

SET UP THE SPIDER-VERSE REWARD
------------------------------
Use:

/collection reward set
collection: Spider-Verse
role: @Your Collection Role
remove_if_incomplete: Yes

The bot immediately checks existing owners. After setup, it automatically
checks both the old and new owner whenever an artifact is transferred, bought,
or traded.

OTHER COMMANDS
--------------
/collection reward view
/collection reward sync collection:Spider-Verse
/collection reward remove collection:Spider-Verse

HOW COMPLETION WORKS
--------------------
A member must own at least one copy of every artifact TYPE in the collection.
For Spider-Verse, that means one Spider-Man, one Web Slinger, and one Friendly
Neighborhood. Owning duplicate copies does not replace a missing artifact type.

By default, the reward role is removed if the member later loses part of the
collection. Set remove_if_incomplete to No to make the role permanent once earned.

BOT PERMISSIONS
---------------
The bot needs Manage Roles, and its highest role must be above the configured
collection reward role.
