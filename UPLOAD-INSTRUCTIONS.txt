DRIPCORE ARTIFACT DELETE UPDATE

1. Open your bot repository.
2. Upload the included src folder into the repository root.
3. Replace the existing file when asked:
   src/commands/economy/artifact.js
4. Redeploy/restart the bot so Discord receives the updated slash command.
5. Use:
   /artifact delete type_id:<TYPE ID> confirmation:DELETE

Optional:
- delete_role:true deletes the Discord collectible role too (default).
- delete_role:false keeps the role but removes it from recorded owners.

WARNING: This permanently removes every numbered copy, all ownership records,
shop stock, marketplace listings, history, preferences, and affected trades.
