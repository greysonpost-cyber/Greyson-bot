DripCore v2.2.12 — Booster Bypass, Roblox Entry & Giveaway Manager Update

Replace the matching src files in your GitHub repository, then redeploy Railway.
Do NOT replace or delete your data folder, bot.sqlite database, .env file, or Railway Volume.

After deployment, run the slash-command deployment once so Discord receives the new options.

Configure roles:
/giveaway-config booster-role role:@Booster
/giveaway-config staff-role role:@Staff
/giveaway-config manager-role role:@Giveaway Manager
/giveaway-config host-role role:@Giveaway Host

New behavior:
- Booster role bypasses required Discord role, guild rank, and DRIP server-tag requirements.
- Clicking Enter opens a Roblox username form.
- The Roblox username is stored with the giveaway entry and displayed in the winner ticket.
- When the winner presses Claim, the host is pinged with the Roblox username.
- Participants are listed from highest entries to lowest.
- Giveaway managers/staff can remove an entry with /giveaway remove-entry.
- Configured Staff and Giveaway Manager roles can use /resolved after escalation.
- /resolved does not lock the winner or host from talking.

This update contains database migrations only. It does not contain a database file and does not erase saved configuration.
