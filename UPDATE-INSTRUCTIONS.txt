DripCore v2.2.11 — Resolved/Ticket Visibility + Command Cleanup

Replace only these files in your project:
- src/handlers/giveawayHandler.js
- src/commands/tickets/resolved.js
- src/index.js
- src/deploy-commands.js

This update does NOT include or replace your database, data folder, .env, or saved configuration.

Changes:
- Fixes /resolved for escalated automatic giveaway tickets.
- Staff cannot view a new giveaway ticket before it is escalated.
- When Escalate is pressed, configured Staff and Giveaway Manager roles gain View Channel and Send Messages, and both roles are pinged.
- /resolved locks the host and winner and displays a Delete Ticket button.
- Removes all slash commands in src/commands/moderation from loading and Discord registration, including ban, kick, mute, unmute, timeout, warn, unban, purge, history, notes, and channel moderation.
- Removes the /ai command and disables mention-based AI replies.
- Old moderation/AI source files can remain in GitHub; the bot now ignores them.

IMPORTANT AFTER UPLOAD:
Redeploy/restart the Railway service. The package start command normally runs deploy-commands.js first. If your setup does not, run `node src/deploy-commands.js` once so Discord removes the old slash commands.
