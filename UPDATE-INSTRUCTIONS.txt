DripCore Giveaway Ticket Permissions + Escalation Update

1. Upload the included src folder into the root of your GitHub repository.
2. Replace the matching files. Do NOT replace or upload your data folder or bot.sqlite database.
3. Redeploy Railway.
4. Redeploy/register slash commands so /resolved and the new giveaway-config options appear.
5. Configure roles:
   /giveaway-config host-role role:@Giveaway Host
   /giveaway-config manager-role role:@Giveaway Manager
   /giveaway-config staff-role role:@Staff

Behavior:
- Giveaway Host role: can view all giveaway tickets but cannot talk unless that member is the actual host.
- Giveaway Manager and Staff roles: can view and talk in all giveaway tickets.
- Escalate pings Staff and Giveaway Manager roles and grants talking access.
- /resolved works only in an escalated giveaway ticket and can be used by Staff, Giveaway Managers, or administrators.
- Resolving closes winner/host messaging and displays a Delete Ticket button.
