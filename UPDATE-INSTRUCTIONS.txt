DripCore v2.2.6 — Small Giveaway Update

1. Do NOT delete your repository or data folder.
2. Upload the included src folder to the root of your GitHub repository.
3. Replace only these two matching files:
   src/handlers/giveawayHandler.js
   src/commands/giveaway/giveaway.js
4. Redeploy Railway.
5. Redeploy/register slash commands so the new /giveaway reroll message_link option appears.

Changes:
- Claim tickets ping only the actual winner and host, not the configured giveaway staff/host role.
- The ticket embed displays the actual prize instead of "Giveaway #ID".
- Winners must display the DRIP server tag. Entries without it are skipped during winner selection/rerolls.
- Manual reroll is now: /giveaway reroll message_link:<paste giveaway message link>
- Existing claim, fulfillment, timeout, transcript, leave-entry, and automatic reroll behavior is preserved.

Persistent data:
- This update contains no data folder and no database file, so it will not overwrite saved configurations.
