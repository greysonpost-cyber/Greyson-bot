# DripCore v2.2.0

Railway-ready Discord.js bot update.

## New in v2.2.0
- Giveaway embeds list every configured bonus-entry role.
- Giveaway entry count and participant list buttons update live.
- Winner tickets automatically add the winner and giveaway host.
- Claim and Fulfilled each require confirmation from both the winner and host.
- Winner tickets include Close, Reopen, and Delete controls.
- Closing or deleting creates an automatic text transcript.
- All standard DripCore embeds use the blue/purple brand endpoints and footer: `DripCore by Greyson`.
- `/command-permissions manage` now uses multi-select command menus instead of typed command names.
