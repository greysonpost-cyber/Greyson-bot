DripCore v2.2.3 Giveaway Claim Update

This is an incremental update. Do NOT delete your repository files.

1. Extract this ZIP.
2. Upload the included src folder to the ROOT of your GitHub repository.
3. Choose Replace/Overwrite for the two matching files.
4. Commit the changes and allow Railway to redeploy.

Changed files:
- src/handlers/giveawayHandler.js
- src/database/db.js

Changes:
- Only the winner presses Claim; the host does not.
- Both winner and host must press Fulfilled before Close is enabled/allowed.
- Unclaimed tickets expire, create a transcript, auto-delete, and reroll.
- Auto-claim winners skip the Claim button and go directly to fulfillment.
- Giveaway channel displays **WAITING ON CLAIM** and updates it to **CLAIMED**.
